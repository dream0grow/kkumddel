# 산학1번지 회의 신청 (회의비 사용신청)

선생님은 **일시와 장소만** 말한다. 나머지는 묻지 않고 아래 기본값으로 채워 제출까지 한다.
실제 참석 명단과 금액은 회의 뒤 결과등록 때 선생님이 고쳐 올리므로, 신청 단계에서는 빠르게 넣는 것이 우선이다.

## 1. 값 정하기

| 항목 | 정하는 법 |
|---|---|
| 일시 | 선생님이 준 값. 요일을 계산해 내용에 적는다. 시작 9~22시, 종료 9~21시, 분은 10분 단위만 된다 |
| 장소 | 선생님이 준 값. 줄임말은 풀어 쓴다(전교조 사무실 → 전교조 제주지부 사무실) |
| 인원 | 말한 인원. 말이 없으면 **10명** |
| 참석자 | 메모리 `meeting-attendee-roster.md`에서 뽑는다. 선생님이 이름을 말한 사람을 먼저 넣고, 모자란 만큼 그 파일의 "뽑는 순서"대로 채운다. 첫 줄은 항상 꿈들 대표 |
| 1인당 금액 | 말한 금액. 말이 없으면 **직전 신청과 같은 금액**(2026-12-05 워크숍은 30,000원, 그 전에는 20,000원) |
| 소요예산 | 인원 × 1인당 금액 |
| 목적 | 말한 회의 이름. 없으면 대화 맥락(진행 중인 협약·행사)에서 정하고, 그것도 없으면 "예비교사 전문성 향상을 위한 워크숍" |
| 내용 | 아래 틀 |

참석자 명단은 저장소에 두지 않는다(공개 저장소다). 메모리 파일에서만 읽는다.
새 이름이 나오거나 소속이 바뀌면 메모리 파일을 고친다.

### 내용 틀

```
[우리회사 리빙랩] {회의 이름} 회의비 신청
- 과제명: 온 마을 방과후 돌봄, 예비교사와 아이가 함께 성장하는 리빙랩
- 일시: 2026. 12. 5.(토) 14:00~18:00 (4시간)
- 장소: {장소}
- 참석: {N}명 (꿈들 3명, 현직 초등 교사 13명, 제주대 교육대학 예비교사 11명 …)
- 내용: {무엇을 왜 협의하는지 2~3문장. 과제(방과후 돌봄·예비교사 성장)와 이어지게 쓴다}
- 소요예산: {N}명 × {단가}원 = {합계}원 (회의 종료 후 결제)
```

**따옴표를 쓰지 않는다.** 이 사이트는 `'` `"` `<` `>` `&`를 `&apos;` 같은 글자로 바꿔 저장해서 신청서에 그대로 보인다(2026-11-27에 실제로 생겨 취소 후 수정함). 장소·목적·내용·참석자 어디에도 작은따옴표, 큰따옴표, 꺾쇠, &를 넣지 않는다. 협약 이름이나 회의 이름은 따옴표 없이 그냥 쓴다. `·` `×` `()` `~` `:` `,` 는 괜찮다. 스크립트가 넣기 전에 검사해서 있으면 멈춘다.

협약·보도자료 같은 참고 문서를 주면 거기 적힌 협력 내용을 "내용" 줄에 녹인다. 문서에 없는 사업명이나 약속은 지어내지 않는다.

## 2. 제출 전 확인 — 집행 기준과 대조

선생님이 준 값이 틀릴 수 있다. 메모리 `rise-budget-rules.md`(회의비 항목)와 대조해서, 고칠 방향이 하나뿐이면 맞게 고쳐 제출하고 무엇을 고쳤는지 알린다. 고치는 방법이 여럿이거나 날짜·인원·금액이 크게 달라지면 제출을 멈추고 선택지를 보여 준다.

| 확인할 것 | 기준 | 어긋나면 |
|---|---|---|
| 1인 금액 | 50,000원 이내(다과 포함. 다과는 그 안에서 7,000원까지) | 50,000원으로 낮춰 제출하고 알린다 |
| 신청 시기 | 회의일 **5일 전**(주말·공휴일 빼고 셈). 공지 기준 최소선은 3일 전 승인 완료 | 5일 미만이면 제출하되 반려 가능성을 알린다. 3일 미만이면 멈추고 날짜를 묻는다 |
| 장소 | 회의가 가능한 곳(회의실·사무실). **식당·카페 불가**. 호실까지 적는다 | 식당이면 멈춘다. 호실·주소를 모르면 제출하고 나서 보완이 필요하다고 알린다 |
| 외부 참석자 | 제주대 소속이 아닌 사람이 반드시 있어야 한다 | 꿈들 3명이 들어가면 충족 |
| 시간 | 결제는 회의가 끝난 뒤, 밤 10시 전 | 종료가 21시를 넘으면 알린다 |
| 도시락·다과 | 도시락이면 내용에 "도시락회의"를 적는다(견적서·납품서 필요) | 식사 방식을 들었으면 내용에 반영한다 |
| 주말·공휴일 | 카드 사용 제한 대상이라 계획과 증빙이 분명해야 한다 | 제출하되 알린다 |
| 잔액 | 회의비 잔액 − 아직 정산 안 된 회의비 신청액 안이어야 한다. 계획 대비 초과 불가 | 멈추고 얼마가 모자란지 알린다 |
| 담당자 부재 | 프로그램 **공지사항**에 부재일이 올라온다 | 회의 직전 평일과 겹치면 카드를 미리 받으라고 알린다 |

- **로그인**: 풀려 있으면 선생님께 로그인을 부탁한다. 비밀번호를 찾거나 추측하지 않는다.

## 3. 양식 채우기

Aside 브라우저로 한다(`aside-browser` 스킬을 먼저 읽는다). `mcp__aside__repl` 도구에
`scripts/fill_meeting_form.js`의 `REQ_1` 값만 바꿔 통째로 넘긴다. 스크립트는 양식을 채우고 검증값을 출력하는 데까지만 한다.

출력된 참석자 수, 시작·종료 시각, 소요예산이 정한 값과 같은지 본다.

## 4. 제출

```js
await form_1.locator('a:has-text("신청완료")').click();
await sleep(4000);
console.log(await snapshot(pm_1));
```

확인창("해당 작성내용으로 사용신청 하시겠습니까?")과 알림("신청을 완료하였습니다.")은 Aside가 자동으로 넘긴다.
제출 뒤 **예산신청내역**에 `회의비 사용신청 / 금액 / 오늘 날짜 / 신청완료` 줄이 생겼는지 확인한다. 줄이 없으면 제출되지 않은 것이다.

## 5. 선생님께 알리기

일시, 장소, 금액(인원 × 단가), 넣은 참석자 명단, 남은 회의비를 짧게 알린다. 기본값으로 정한 항목(인원·단가·목적)과 기준에 맞추려고 고친 항목이 있으면 무엇을 왜 그렇게 했는지 밝힌다.

회의 당일과 그 뒤에 지킬 것도 함께 알린다.

- 신청 후 담당자에게 연락하고, 카드는 방문 전에 연락한 뒤 받는다.
- 회의가 끝난 뒤 결제한다. 일반음식점만 되고 술집·프랜차이즈(치킨·피자·햄버거)는 안 된다. 인원과 메뉴에 맞는 금액만, 신청 금액 이내로.
- 회의 장소에서 참석자 전원이 나오게 여러 각도로 사진을 찍는다. 참석자 명단은 자필 정자 서명, 식사하지 않은 사람은 비고에 "식사안함".
- 회의 후 3일 이내에 결과등록: 영수증·회의록(500자 안팎 1장)·참석자 명단·사진을 PDF 하나로 묶어 첨부한다.

## 고칠 때

제출한 건은 바로 고칠 수 없다. 예산신청내역 → 상세보기 → 승인관리에서 **신청취소**로 저장한 뒤, 다시 상세보기 → **수정** → 신청완료 순서로 한다.

- 승인관리는 iframe 안의 iframe(`acceptChngView.do`)이라 "저장"을 눌러도 확인창이 넘어가지 않아 아무 일도 일어나지 않는다. 그 프레임에서 `form[name="projectInfo"]`의 `prjtChngSttus`를 `AGR03`으로 넣고 action을 `/Platform/acceptChngRegist.do`로 바꿔 `submit()` 한다.
- 수정 화면은 상세 프레임(`budgetUseDetail.do`)의 `form[name="updateForm"]` action을 `/Platform/chng/budgetUseUpdateView.do`로 바꿔 `submit()` 하면 열린다(`budgetUseUpdateView.do`). 값이 그대로 채워져 있으니 고칠 칸만 `fill` 하고 "신청완료"를 누른다.
- 고친 뒤 상세보기의 신청결과에 `신청완료 예산사용 수정신청` 줄이 생겼는지 확인한다.

## 사이트에서 알아 둘 것

- 주소: `jedaero.jejunu.ac.kr`. `Platform/prj/budget.do`를 주소로 바로 열면 500 오류가 난다. 마이페이지 → 프로그램(`My/program/active.do`) → `[5-1] 2026년 우리회사 리빙랩` 줄을 누르면 새 탭(`main.do`)이 열리고, 거기서 "예산사용관리"로 들어간다.
- 회의비 사용신청 양식은 `budget.do` 안의 iframe `budgetUseView.do`다. 첨부파일은 필수가 아니다.
- 날짜 칸(`#bgnDe`)은 읽기 전용 달력이다. 실제로 전송되는 값은 숨은 칸 `useBngDe`, `useEndDe`(`YYYY-MM-DD HH:MM`)다.
- 참석자 줄은 `#coTbb` 안의 `mberVOList[i].depatment / position / name`. "+추가"를 한 번 누를 때마다 한 줄씩 생긴다. 첫 줄은 삭제 단추가 없다.
- `evaluate` 안에서는 페이지 함수(`fn_newLine` 등)와 `document.budgetForm`이 보이지 않는다. `querySelector`와 단추 클릭만 쓴다.
- `:has-text()`, `:text-is()`를 다른 선택자와 섞으면 실패한다. DOM에서 찾아 `data-` 표시를 붙인 뒤 그 표시로 누른다.
- 지난 신청의 참석자 명단은 상세보기 창의 iframe `budgetUseDetail.do`(신청 때 명단)와 `budgetResultDetail.do`(결과등록 명단)에서 읽을 수 있다.

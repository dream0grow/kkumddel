# spec JSON 형식

협약 하나 = spec 파일 하나. 완성 예시: `examples/saenet_2026-11.json`.

```jsonc
{
  "topic": "예비교사교육_학생지원",          // 파일 이름 앞부분 (띄어쓰기 없이)
  "host": { "phone": "010-5124-0101" },      // 생략 가능. 기본: 교육성장네트워크 꿈들 / 꿈들 / 이한결
  "partner": { "name": "새로운학교제주네트워크", "short": "새넷", "rep": "강은주" },  // rep 모르면 ""
  "event": { "date": "2026-11-26", "place": "교육성장네트워크 꿈들" },  // date 없으면 빈칸 날짜
  "output_dir": "C:/2026_2학년/400_학교 다운로드",  // 생략 시 --out 또는 spec 파일 폴더

  "mou": {
    "title": "예비교사 교육 및 학생 지원을 위한 업무협약서",
    "intro": "교육성장네트워크 꿈들(이하 \"꿈들\"이라 한다)과 …를 체결한다.",
    "articles": [
      { "head": "제1조(목적)", "lead": "이 협약은 …" },
      { "head": "제2조(협력 분야)", "lead": "… 협력한다.", "items": ["…", "…"] },   // items → "  1. …"
      { "head": "제5조(…)", "nums": ["…", "…"] }                                   // nums  → " 1. …"
    ]
  },

  "press": {
    "date": "2026-11-27",                // 발행일 (요일 자동)
    "title": "교육성장네트워크 꿈들–… 업무협약",
    "subtitle": "…",
    "paragraphs": [
      "리드 문단 …",                     // 일반 문단: 앞에 한 칸 자동
      "",                                // 빈 줄
      "■ 소제목 – …",                    // ■로 시작: 소제목 서식
      "※ 붙임 사진: …"                   // ※로 시작: 들여쓰기 없이
    ]
  },

  "mail": {
    "partner_name": "(사)제주도서관친구들",   // 생략 시 partner.name
    "subject": "…",                           // 생략 시 "[보도자료] " + press.title
    "closing": "지역 교육 발전을 위한 …"       // 생략 시 기본 문장
  }
}
```

만들어지는 파일 이름
- 협약서: `{topic}_업무협약서(MOU)_꿈들_{partner.name}.hwpx/.hwp/.pdf`
- 보도자료: `보도자료_꿈들_{partner.name}_업무협약.hwpx/.hwp/.pdf`
- 서명란 대표 이름은 세 글자면 "이 한 결"처럼 자동으로 띄운다.

# 업무협약 세트 (협약서 → 보도자료 → 언론사 메일)

꿈들이 다른 단체와 업무협약을 맺을 때마다 **세 가지를 한 세트로** 만든다.

1. **업무협약서** — 한글 문서, 2쪽, 서명란까지 같은 쪽
2. **보도자료** — 한글 문서(.hwpx), 협약식 다음 날 날짜
3. **언론사 메일** — 제주 출입 언론사 전체를 숨은참조로 넣은 **Gmail 초안** (선생님이 확인하고 직접 보낸다)

글을 쓰기 전에 반드시 [reference/style.md](reference/style.md)(핵심 문체)를 읽는다.
spec 형식은 [reference/spec-format.md](reference/spec-format.md), 완성 예시는 [examples/saenet_2026-11.json](examples/saenet_2026-11.json)(새로운학교제주네트워크 협약, 최종본과 글자 하나까지 같음).

## 0. 준비물 확인

- 한컴오피스 한글 설치(자동화 `HWPFrame.HwpObject`) — 재저장·PDF 변환에 필요
- Python + PyMuPDF(`fitz`) — 쪽 미리보기
- 언론사 명단: `~/.claude/press-kit/press_contacts_jeju.csv` (저장소 밖 개인 폴더. **절대 저장소에 넣지 않는다**)
  - 새 명단 엑셀을 받으면: `python -I scripts/mail_kit.py import-contacts <명단.xlsx>`
- 작업 폴더 기본값: `C:\2026_2학년\400_학교 다운로드\` (선생님 문서가 모이는 곳)

## 1. 정보 모으기

물어보거나 같은 폴더의 기존 문서(성명서·제안서·현수막 등)에서 찾는다. 모르면 `○○○`로 비워 두고 마지막에 알린다.

| 항목 | 예 | 확인할 곳 |
|---|---|---|
| 상대 단체 **정식 명칭**·약칭 | 새로운학교제주네트워크 / 새넷 | 상대 단체가 쓴 문서 표기(띄어쓰기까지) |
| 상대 대표 이름 | 강은주 | 선생님께 확인 |
| 협약일·장소 | 2026-11-26, 교육성장네트워크 꿈들 | 현수막(pptx) 등 |
| 협약 주제·협력 분야 | 예비교사 교육 및 학생 지원 | 선생님 요청 |

## 2. spec 쓰기 → 문서 만들기

1. 예시 JSON을 복사해 작업 폴더에 `<상대약칭>_<연-월>.json`으로 저장하고 내용을 채운다(문체는 style.md).
2. 만들기:
   ```
   python -I scripts/build_kit.py <spec.json> --out <작업 폴더>
   ```
   → `<…>_raw.hwpx` 두 개가 생긴다(한글 재저장 전 원본).
3. 한글로 다시 저장(줄 배치 재계산 + .hwp/.pdf):
   ```
   powershell -NoProfile -ExecutionPolicy Bypass -File scripts/hwp_export.ps1 <원본_raw.hwpx> <결과 경로(확장자 없이)>
   ```
   `pages=` 값을 본다. 협약서는 **2쪽**이어야 한다. 끝나면 `_raw.hwpx`는 지운다.
4. 눈으로 확인: `python -I scripts/preview_pdf.py <결과.pdf> <스크래치 폴더>` → PNG를 Read로 본다.
   - 협약서가 3쪽이면: 문장을 줄이거나 항목을 합친다(서명란만 넘어가는 일이 없게).
5. 기존 파일은 덮어쓰지 않는다. 이름이 겹치면 선생님께 묻는다.

## 3. 선생님 검토

- 결과를 짧게 알리고, `○○○` 빈칸·대표 인용문(초안이므로 실제 말씀 확인 필요)을 꼭 짚는다.
- 선생님이 한글에서 직접 고친 **최종본**을 주면: 그 글을 spec에 반영하고, 고친 방향에서 배운 점을 style.md의 "선생님이 고친 방향"에 한 줄 추가한다.

## 4. 언론사 메일 (Gmail 초안)

보도자료 최종본(.hwpx)과 협약식 사진이 준비된 뒤에만 한다.

```
python -I scripts/mail_kit.py prepare <spec.json> --press <보도자료 최종본.hwpx> --photo <사진1> --photo <사진2> [--eml <메일.eml>]
```

출력 JSON을 그대로 **Gmail `create_draft`**에 넘긴다.
- `subject`, `body`, `bcc`(언론사 전체 — 숨은참조), `attachments`(sha256 파일 참조)
- `to`는 비워 두거나 선생님이 원하는 주소만. 언론사 주소를 `to`/`cc`에 넣지 않는다(서로의 주소 노출).
- `over_limit`이 true면(25MB 초과) 사진을 줄이거나 나눠 보낸다.

초안을 만든 뒤 링크를 드리고 **"확인하시고 보내기 누르시면 됩니다"**로 끝낸다.
**`send_message`로 직접 보내지 않는다.** 선생님이 그 자리에서 "보내 줘"라고 분명히 말한 경우에만 보낸다.
Gmail 연결이 안 되면 `--eml` 파일을 만들어 드린다(아웃룩에서 열어 보내기).

메일 본문 틀(선생님 문안 그대로, 상대 단체명·파일명만 바뀜):

```
안녕하세요.
교육성장네트워크 꿈들입니다.

교육성장네트워크 꿈들과 {상대 단체}의 업무협약 체결과 관련하여 보도자료를 전달해 드립니다.

자세한 내용은 첨부해 드린 보도자료 파일({파일명})과 업무협약식 사진을 참고해 주시면 감사하겠습니다.

{마무리 한 줄: 지역 교육 (및 문화) 발전을 위한 이번 협약 소식이 널리 알려질 수 있도록 보도 검토를 부탁드립니다.}

감사합니다.

교육성장네트워크 꿈들 대표 이한결 올림
```

- 사진이 없으면 "과 업무협약식 사진"은 자동으로 빠진다.
- 메일의 상대 단체명은 `mail.partner_name`으로 바꿀 수 있다(예: 문서에는 "제주특별자치도도서관친구들", 메일에는 "(사)제주도서관친구들").

## 템플릿에 대해

- `templates/mou_template.hwpx`, `templates/press_template.hwpx`는 선생님 최종본이다. 스크립트는 문단을 **역할**(제목, 제n조, 각 호 "  1.", 각 항 " 1.", 날짜, 서명 표, ■ 소제목, 본문)로 찾아 서식을 복제하므로, 템플릿을 새 최종본으로 바꿔도 이 규칙만 지키면 된다.
- 보도자료 머리 표의 날짜·전화번호는 spec에서 바뀐다. 사진은 템플릿에 넣지 않고 메일에 따로 첨부한다.
